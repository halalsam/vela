Dynamic Type. Every style scales xSmall → AX5. Layouts reflow to a single column at accessibility sizes; numbers never truncate.

Tracking. Use SF's built-in optical tracking per size — no manual letter-spacing in the app. Web: −0.02em on 28px and above.

Arabic. SF Arabic at the same point sizes, line height +2pt for diacritics. Western digits for prices and data in both languages.
